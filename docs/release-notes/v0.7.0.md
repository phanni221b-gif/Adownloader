## 변경 사항

- **백그라운드 다운로드가 멈추지 않습니다.** 영상 요청을 브라우저(Gecko)가 직접 보냅니다. 재생할 때와 같은 로그인 정보를 쓰므로, 탭을 닫거나 앱을 백그라운드로 보내거나 앱이 재시작돼도 다운로드가 계속됩니다. 안 되는 사이트에서는 기존 방식으로 자동 전환됩니다.
- **자동 이어받기.** Android가 다운로드를 잠시 중단시키거나, 앱이 강제 종료되거나, 네트워크·서버 오류가 잠깐 나면 저장된 지점부터 자동으로 이어받습니다. 진척 없이 4번 연속 실패하면 멈추고, 직접 누른 일시정지는 그대로 유지됩니다.
- **영상 주소 만료 대응.** 오래 걸리는 다운로드 중에 영상 주소가 만료되면 영상 목록을 다시 받습니다. 같은 영상, 같은 화질일 때만 그대로 이어받습니다.
- **광고·인트로가 붙은 HLS 영상 지원.** 이전에는 실패하던 영상을 화질 손실 없이 하나의 파일로 이어 붙입니다. 중간에 해상도나 코덱이 바뀌는 영상은 깨진 파일을 만들지 않고 이유를 안내합니다.
- **HLS 다운로드 속도 개선.** 영상 조각을 4개씩 동시에 받습니다.
- **다운로드별 알림.** 동시 다운로드마다 알림이 따로 표시되고, 일시정지·취소 버튼이 해당 다운로드에만 적용됩니다.

### 알려진 제한
- Gecko 경로는 요청 출처(Referer)를 사이트 주소까지만 보냅니다. 페이지 주소까지 정확히 요구하는 서버는 첫 요청에서 기존 방식으로 자동 전환됩니다.
- 실제 사이트에서 장시간 백그라운드로 받는 동작과 Galaxy Fold 실기기 동작은 실기기에서 확인이 필요합니다.
