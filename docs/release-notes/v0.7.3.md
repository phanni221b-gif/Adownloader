## 변경 사항

- **보호 판정을 본문으로 검증합니다.** 이전에는 서버 응답 헤더(`x-relay-envelope`)만 보고 "암호화 전송"으로 판정하는 빠른 경로가 있었습니다. 이제 응답 **본문의 실제 데이터**를 확인해, 본문이 정말 암호화돼 있을 때만 "암호화 전송"으로 표시합니다.
- **오탐 방지.** 헤더만 그렇게 표시됐을 뿐 본문이 실제로는 일반 영상(HLS 등)인 경우, 암호화로 오판하지 않고 **다운로드 가능한 영상으로** 인식합니다. 광고·중계 요청을 영상으로 오인하는 경우도 줄어듭니다.
- **상세 사유 구분.** 본문까지 확인된 암호화와, 응답을 읽을 수 없어 헤더 표시만으로 판단한 경우를 구분해 보여 줍니다.
