## 변경 사항

### 실패 보고서가 거부된 경로를 정확히 표시 (공통 로직)

v0.8.9 기기 보고서(VPN 켬)에서 확인된 표시 오류를 고쳤습니다.

- 실제 거부는 **브라우저 엔진 경로**가 서버 이동(리디렉션) 뒤 CDN에서 받은 **HTTP 403**인데, 보고서의 실패 항목에는 경로가 `native`(직접 연결)로 표시됐습니다.
- 이벤트 기록 마지막에는 직접 연결이 첫 번째 사이트에서 **403을 받은 것처럼** 보이는 항목(`MANIFEST_NATIVE_BLOCKED`)이 추가됐습니다. 실제로 직접 연결은 그 요청에 **200(HTML)** 을 받았으므로 사실과 다른 기록이었습니다.
- 이제 실패 항목은 실제로 거부된 경로(`gecko`), 호스트, 상태 코드, 리디렉션 단계를 그대로 표시하고, 존재하지 않은 직접 연결 403은 기록하지 않습니다.

이 수정은 진단 기록만 바로잡습니다. **다운로드 동작은 바뀌지 않으며, 이 변경으로 해당 사이트의 다운로드가 되는 것은 아닙니다.**

> HTTP 403은 `ACCESS_BLOCKED`로 분류하며 DRM으로 단정하지 않습니다. DRM 해제·보호 우회·사이트별 예외는 구현하지 않습니다. 개인정보 보호 정책 그대로, 기존 서명키 유지.
