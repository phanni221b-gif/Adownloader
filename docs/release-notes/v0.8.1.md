## 변경 사항

- **세그먼트가 매니페스트와 다른 호스트(안티봇 CDN)에서 제공될 때 다운로드가 막히던 문제 개선.** v0.8.0으로 매니페스트(`.m3u8`)는 받아지지만, 영상 조각(세그먼트)이 다른 호스트에서 **안티봇 챌린지(HTTP 403)**로 걸리는 경우가 있었습니다. 한 번 직접 연결로 전환되면 전송 내내 직접 연결만 쓰도록 고정돼, 챌린지를 통과한 **브라우저 세션(로그인/통과 쿠키)**을 쓰지 못했습니다. 이제 직접 연결이 차단되면 해당 요청을 **브라우저 네트워크로 재시도**하고(재생에 쓰인 것과 같은 쿠키·TLS 사용), 그런 호스트는 기억해 이후 세그먼트는 처음부터 브라우저 경로로 받습니다.

> 안티봇이 "통과 쿠키" 방식이면 이 변경으로 받아집니다. 다만 매 요청마다 자바스크립트 챌린지를 요구하는 사이트라면, 탭이 아닌 요청으로는 여전히 통과가 어려울 수 있습니다(그 경우 보고서로 확인해 이어서 처리합니다). DRM 해제·보호 우회·비인가 키 추출은 구현하지 않습니다. 개인정보 보호 정책(쿠키·인증 값·응답 본문 미기록)은 그대로이며, 기존 서명키를 유지합니다.
