## 변경 사항

- **브라우저에서는 재생되는데 다운로드만 "사이트 요청 차단(HTTP 403)"으로 실패하던 일반 HLS 문제 수정.** DOM(`<video>`)에서 감지된 영상은 네트워크 요청이 캡처되지 않아, 매니페스트(`.m3u8`) 요청이 **Referer 없이, 브라우저가 아닌 기본 User-Agent로** 나갔습니다. 핫링크/안티봇 보호가 걸린 CDN은 이런 요청을 403(HTML 차단 페이지)으로 거부합니다. 이제 캡처된 맥락이 없을 때 **페이지 주소를 Referer로, 실제 브라우저 엔진의 User-Agent를** 함께 보내, 사이트의 플레이어가 보내는 것과 동일하게 요청합니다. (DRM·세션과 무관한 평범한 HLS 차단 문제였습니다.)
- 캡처된 Referer·User-Agent가 있으면 그대로 사용하고, 없을 때만 보완합니다(기존 동작 유지).

> DRM 해제·보호 우회·비인가 키 추출은 구현하지 않습니다. 이것은 사이트가 재생에 쓰는 것과 동일한 정상 요청 헤더를 보내는 것뿐입니다. 개인정보 보호 정책(쿠키·인증 값·토큰·응답 본문 미기록)은 그대로입니다. 기존 서명키를 유지하므로 덮어서 설치할 수 있습니다.
