## 변경 사항 (화면 개편)

- **더 넓은 주소창.** 폰 화면에서는 뒤로/앞으로 버튼을 숨기고 주소창을 넓혔습니다. 뒤로는 시스템 뒤로가기, 앞으로는 메뉴(⋮ → 앞으로)에서 쓸 수 있습니다. 폴드를 펼쳤을 때는 버튼이 그대로 보입니다.
- **깔끔한 주소 표시.** 평소에는 `사이트/경로`만 짧게 보여 주고, 주소창을 누르면 전체 주소가 선택된 상태로 나옵니다.
- **다운로드 진행 정보.** 진행률(%), 받은 크기, 속도, 남은 시간이 표시됩니다. 진행률이 다른 문구에 가려 보이지 않던 문제도 고쳤습니다.
- **다운로드 탭 배지.** 다른 화면에서도 진행 중인 다운로드 개수가 하단 탭에 보입니다.
- **설정 화면 정리.** 항목마다 현재 값(동시 다운로드 개수, 알림, 테마)을 보여 주고, 진단 기능은 맨 아래 "문제 해결"로 모았습니다.
- **다른 앱에서 링크 열기.** 다른 앱에서 링크를 공유하거나 열 때 "Adownloader에서 열기"를 고르면 새 탭으로 열립니다.
- 하단 탭 "플레이어"의 이름을 화면 제목과 같은 "내 영상"으로 바꿨습니다.
