## 변경 사항

- **인가 재생 세션의 `/resource` 주소 지원.** 일부 사이트는 인가 재생 세션(앱이 사이트의 공개 핸드셰이크로 직접 세션을 만들어 받는 방식)의 주소를 `/media/<식별자>/resource` 형태로 제공합니다. 이 형태가 지원 목록에서 빠져 있어, 같은 방식인데도 "보호된 전송"으로 잘못 분류돼 다운로드가 막혔습니다. 이제 이 주소 형태도 기존 세션 엔진으로 정상 처리합니다.
- **판정 표시 정확화.** 응답 본문을 확인하지 못한 경우(브라우저 엔진이 본문 열람 API를 제공하지 않는 경우)에는 "암호화 확정"이 아니라 "보호 방식 미확인"으로 표시합니다. 본문까지 실제 암호화가 확인된 경우에만 "암호화 전송"으로 표시합니다.

> DRM 해제, 보호 우회, 비인가 키 추출은 구현하지 않습니다. 위 세션은 사이트가 공개적으로 제공하는 핸드셰이크로 앱이 직접 만든 세션이며, 브라우저 키를 빼오지 않습니다.
